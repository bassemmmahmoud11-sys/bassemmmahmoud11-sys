## 🚀 Featured Projects

### 📊 End-to-End Analytics Pipeline for Electronics Retail
Cleaned and structured raw sales, manpower, and payroll data from 3 source systems, then designed a normalized SQL Server database (8 tables, dbo + sales schemas). Built an interactive Power BI HR dashboard with DAX measures, ran EDA in Python across 20,000+ sales records, and built an OLS regression model (statsmodels) linking order price to total value — **R² = 0.69**.

**Tools:** SQL Server · Power BI · Excel · Python (Pandas, statsmodels, Plotly)
🔗 [View Repository](https://github.com/bassemmmahmoud11-sys/E-Tech-Sales---HR-Analytics-Project)

### 🏥 Hospital Management System (SQL)
Designed a normalized (3NF) SQL Server database with 7 interconnected tables, foreign keys, check constraints, and a computed column for patient age. Built 7 analytical queries using window functions (`DENSE_RANK`, `PARTITION BY`) and CTEs, plus 3 reusable reporting views and a parameterized stored procedure. Added 3 targeted indexes to optimize scheduling, billing, and lab-history lookups.

**Tools:** SQL Server · T-SQL · Views · Stored Procedures · Window Functions · Indexing
🔗 [View Repository](https://github.com/bassemmmahmoud11-sys/Hospital-Management-System)
